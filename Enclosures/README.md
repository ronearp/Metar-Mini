Designer print profile: PETG (PLA also acceptable), 0.4 mm nozzle, 0.2 mm layers, 2 walls, 15% infill, textured PEI, automatic tree supports and automatic brim. Print front and rear. Mount display to front using M2 × 5 mm screws, route USB and join the halves. No BME280 or sensor wiring is needed for this project. Check physical fit before final assembly.
