# METAR Mini v4.5

- Darker VFR green, black background and white headings.
- Automatic, filtered and manual runway modes; alternate W13/KW13 runway matching.
- Manual runway pairs accepted without entering headings.
- Wind notation changed to `direction @ speed kt`.
- Up to 20 airports, Wi-Fi rescan, manual SSID, saved rotation interval and batched METAR requests.
- Original third-party enclosure and documentation included; preferred Aura enclosure linked only.

The uploaded source was preserved except for the agreed wind-format change. No new compilation or bench test was performed for this package. Verify the reconstructed TFT_eSPI header and compile/upload before tagging a release.
